# Релизный пакет

`build_release.sh` собирает каталог, который загружается вместе с диссертацией: исходники трёх репозиториев по одному
коммиту, собранную страницу SquadCalc, документы, проверку на секреты и манифест, связывающий всё это. English version:
[`README.md`](README.md).

```sh
tools/release/build_release.sh                       # -> ~/work/release/<сегодня>/ из веток dev
tools/release/build_release.sh --out /tmp/rel --date 2026-11-04 --no-dist
tools/release/build_release.sh --scan-only <каталог> # только проверка на секреты, код 0 чисто / 2 найдено
tools/release/test_scan.sh                           # проверка на подставных секретах
```

| параметр | смысл |
|---|---|
| `--out DIR` | куда класть пакеты (по умолчанию `~/work/release`); пакет — `DIR/<дата>/` |
| `--date YYYY-MM-DD` | имя пакета (по умолчанию сегодня) |
| `--ref BRANCH` | ветка или коммит, который архивируется во всех трёх репозиториях (по умолчанию `dev`) |
| `--no-dist` | не собирать webpack (в манифесте тогда нет dist) |
| `--deny-list FILE` | строки (по одной в строке, без учёта регистра), которых не должно быть: ники игроков, имена хостов. Файл держите вне репозиториев |
| `--force` | заменить пакет с той же датой |
| `SQUADCALC_REPO`, `SB_REPO`, `AGL_REPO` | пути к репозиториям (по умолчанию `~/agl/SquadCalc`, `~/dev/Squad-Ballistics`, репозиторий скрипта) |

## Что в пакете

| файл | содержимое |
|---|---|
| `SquadCalc-<коммит>.tar.gz`, `Squad-Ballistics-<коммит>.tar.gz`, `agl-<коммит>.tar.gz` | `git archive` головы ветки (только закоммиченное; незакоммиченная работа не входит); 12 символов коммита — в имени |
| `SquadCalc-dist-<коммит>.tar.gz` | `npm run build` архивных исходников SquadCalc без каталогов `heightmaps/` и `maptiles/` (эти данные раздаются отдельно и в загрузку диссертации не входят) |
| `docs/` | README, `CHANGELOG.md`, `RELEASE_NOTES.md` (RU + EN в одном файле), `tools/volumetric/docs/*.md`, `docs/*.md` репозитория инструментов (отчёт о методах и результатах) и таблицы оценки (`engine/tests/last-run-precision.txt`, `engine/wgsl/test/last-run*.txt`, `tools/volumetric/data/*.json`) |
| `MANIFEST.json` | по каждому репозиторию: ветка, полный хеш коммита, дата и тема коммита, версия (SquadCalc — `package.json`; Squad Ballistics — `APP_VERSION` в `config.py`, он должен совпадать с первым заголовком `RELEASE_NOTES.md`, иначе сборка останавливается); примечание о dist; результат проверки; размер и SHA-256 каждого файла |
| `SHA256SUMS` | те же хеши (и хеш манифеста) для `sha256sum -c` |

Архивы и dist побайтно воспроизводимы для тех же коммитов: `git archive` и `gzip -n`, tar dist отсортирован, владелец 0,
время — время коммита.

Dist собирается в черновой копии архивных исходников, рабочая копия не трогается. Две вещи берутся из локальной копии,
потому что их нет в git: `node_modules` (сначала `npm ci` в SquadCalc) и `public/engine` (wasm-сборка движка на Rust,
`npm run build:engine`; без неё в dist нет слоя объёмов, и манифест это говорит). `API_URL` — заглушка
`https://example.invalid/api`: настоящий адрес из `.env` никогда не читается.

## Проверка на секреты

Идёт по распакованным архивам, собранной странице и копиям в `docs/` до того, как что-либо попадёт на место. Находка
печатается как `SECRET-SCAN FAIL rule=<имя> at=<файл>:<строка>` (найденный текст не печатается), черновой пакет удаляется,
код выхода 2. Правила (`SECRET_RULES` в скрипте): закрытые ключи PEM; ключи AES (литерал `0x` + 64 hex или 64 hex / 43
символа base64 рядом со словами «aes key» / «encryption key»); токены GitHub, Slack, Telegram, Google, AWS и `sk-`; JWT;
`password`, `passwd`, `rcon_password`, `secret`, `token`, `api_key`, `authorization` со значением в кавычках от 8
символов; строка `Password=` (`Rcon.cfg` Squad); Steam ID (`7656119` + 10 цифр); имена файлов `.env`, `*.pem`, `id_rsa*`,
`id_ed25519*`, `*.key`, `*.p12`, `*.pfx`, `*.ppk`, `.netrc`, `*.kdbx`.

Пределы, названные прямо, чтобы проверке не доверяли сверх меры:

* Steam ID с шестью нулями подряд среди цифр (`76561198000000000`) считается заведомо вымышленным; такие ID в тестовых
  данных `tools/hit_check`. У настоящего ID этого практически не бывает.
* Ники игроков и имена хостов шаблоном не найти. Используйте `--deny-list`.
* Проверяется только закоммиченная голова, не история git, и не проверяются бинарные файлы. Секрет, удалённый из головы,
  но оставшийся в старом коммите, в архивах отсутствует, а в репозиториях есть: сами репозитории публиковать нельзя.
* Значения-заглушки в угловых скобках, переменные shell (`$X`) и фигурные скобки правило паролей не отмечает.

`test_scan.sh` подставляет по одному ложному секрету на правило во временное дерево (собираются при запуске, так что в
самом тесте их нет), требует код 2 с нужным правилом и код 0 на чистом дереве, на вымышленном Steam ID и на заглушке.

## Перед загрузкой

1. Влить работу в `dev` во всех трёх репозиториях; пакет собирается из головы `dev`.
2. Прогнать тесты репозиториев (SquadCalc `npm test`, Squad Ballistics `pytest`); пакет их не запускает.
3. Запустить сборку, прочитать последние строки (`SECRET-SCAN OK`, `SHA256SUMS verified`) и вставить `MANIFEST.json` в
   текст подачи. Репозитории закрытые, публичный выпуск разрешён только с 2027 года.
